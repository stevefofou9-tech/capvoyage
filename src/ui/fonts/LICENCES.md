# Polices hébergées

Fichiers woff2 (sous-ensemble latin) récupérés auprès de Google Fonts le 24/10/2026 et servis par l'application
elle-même pour que l'interface reste identique hors ligne (aucun appel à un service tiers à l'exécution).

| Fichier | Famille | Licence |
|---|---|---|
| `public-sans-v21-latin.woff2` | Public Sans (variable, graisses 500 à 800) | SIL Open Font License 1.1 |
| `atkinson-hyperlegible-v12-latin-400.woff2`, `-700`, `-400-italic` | Atkinson Hyperlegible | SIL Open Font License 1.1 |

Le nom du fichier porte la version de la police : changer de version, c'est changer de nom, ce qui permet
un cache long sans risque de version périmée (ADR-009).
